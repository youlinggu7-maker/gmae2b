# 柔和低多邊形 3D 資產

已選風格：柔和低多邊形 3D 夢境場景。

產物：

- `little_dream_demon_lowpoly.blend`：可編輯 Blender 場景
- `little_dream_demon_lowpoly.glb`：可匯入 Godot 的 GLB，含動畫
- `create_lowpoly_scene.py`：可重現產生場景、角色、材質、燈光與動畫
- `export_glb.py`：重新輸出 GLB

場景包含月光房間、窗格、平台、霧石、低多邊形小夢魔、金色 KEY，以及角色上下浮動和 KEY 旋轉動畫。背景 Eevee 預覽受本機 Vulkan 驅動限制未輸出 PNG，但 `.blend` 與 `.glb` 已成功建立。

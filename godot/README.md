# Godot Web export

1. Install Godot 4.x and the Web export template.
2. Open `project.godot` in this folder.
3. Run the project to test.
4. Project > Export > Add… > Web.
5. Export to `../web/` with `index.html`.
6. Deploy the exported `web/` contents to GitHub Pages.

This source intentionally uses only Godot UI nodes and code-generated colors, so it remains usable before Blender assets are available.
